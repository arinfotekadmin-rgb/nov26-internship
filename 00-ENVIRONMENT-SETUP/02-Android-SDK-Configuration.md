# 02. Android SDK Configuration

## Learning objectives

- Explain what the Android SDK contains.
- Locate the SDK Manager.
- Install SDK platforms and tools.
- Understand the difference between compile SDK and minimum SDK.
- Verify SDK installation.

## 1. What is the Android SDK?

The Android Software Development Kit (SDK) contains the platform APIs, build tools, platform tools, emulator components and other packages required to build and test Android applications.

Android Studio is the IDE. The SDK provides the Android development components used by the IDE and build system.

## 2. Open SDK Manager

From the Android Studio Welcome screen:
1. Select More Actions.
2. Select SDK Manager.

From an open project:
1. Open File.
2. Select Settings.
3. Navigate to Languages & Frameworks, then Android SDK. Menu labels can vary by release.

The SDK Manager displays the SDK location and package tabs.

## 3. SDK Platforms

The SDK Platforms tab lists Android API platform packages.

Install the platform recommended by the Android Studio project wizard. You may install additional platforms when you need to test compatibility with older or newer Android versions.

Understand these settings:

- `compileSdk`: Android API level used to compile your source code.
- `minSdk`: Lowest Android API level your app declares support for.
- `targetSdk`: Android API level whose behaviour and compatibility requirements your app opts into.

These values serve different purposes. Do not set them to the same number automatically. Follow current Android requirements and your application's device-support policy.

For the learning project, use the values generated by the current Android Studio template unless a chapter explicitly asks you to change them.

## 4. SDK Tools

Open the SDK Tools tab. Common tools include:

| Tool | Purpose |
|---|---|
| Android SDK Build-Tools | Build and package Android applications |
| Android SDK Platform-Tools | Includes tools such as `adb` |
| Android SDK Command-line Tools | SDK management and command-line utilities |
| Android Emulator | Runs virtual Android devices |
| Emulator hypervisor driver / platform support | Helps emulator performance where supported |

Install the current recommended versions. Some tools may already be installed by the setup wizard.

## 5. SDK location

A common Windows default is:

```text
C:\Users\<your-user>\AppData\Local\Android\Sdk
```

If you want the SDK on D: drive, create a folder such as:

```text
D:\Android\AndroidSDK
```

In SDK Manager:
1. Locate Android SDK Location.
2. Change it to the intended folder.
3. Apply the change.
4. Install the required packages into that location.

Do not move an active SDK folder manually in File Explorer. Change the configured SDK location through Android Studio and install or migrate packages through the SDK Manager.

## 6. Verify Android Debug Bridge

`adb` is included in Platform-Tools.

Open PowerShell and run the command using your actual SDK path:

```powershell
& "D:\Android\AndroidSDK\platform-tools\adb.exe" version
```

If your SDK is in the default location, use that path instead.

Expected result: Android Debug Bridge version information is displayed.

## 7. Troubleshooting

### SDK location not found
- Open SDK Manager.
- Check the SDK path.
- Confirm that the directory exists.
- Reinstall missing packages.

### Package download fails
- Retry through SDK Manager.
- Check firewall and proxy settings.
- Avoid downloading SDK archives from unofficial sources.

### `adb` is not recognised
- Use the full path to `adb.exe`, or add the SDK `platform-tools` directory to your user PATH.
- Open a new terminal after changing PATH.

# Batch 5: Advanced Android Development

**Duration:** 2 weeks  
**Prerequisites:** Kotlin basics, Android fundamentals, Jetpack Compose layouts, state, navigation, ViewModel and coroutines.

## Learning outcomes
By the end of this batch, you should be able to:
- Organise a medium-sized Android application into maintainable layers.
- Use ViewModel and lifecycle-aware state collection.
- Handle loading, success, empty and error states.
- Store suitable data locally using DataStore and Room.
- Implement background work with WorkManager.
- Handle runtime permissions and app lifecycle changes.
- Add app-level logging, crash diagnostics and tests.
- Build a release-ready application module.

## Required practical project
Create a local-first Student Dashboard prototype. It should show a student profile, saved course list, recently viewed items and a background refresh status. API integration is covered in Batch 6.

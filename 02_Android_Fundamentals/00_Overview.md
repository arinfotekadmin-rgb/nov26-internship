# Batch 3: Android Fundamentals

**Goal:** Understand Android app structure, lifecycle, navigation, permissions, storage, networking and debugging.

**Prerequisite:** Complete Batch 1 installation and Batch 2 Kotlin fundamentals.

## Chapters
1. Android platform and app structure
2. Android Studio project structure and Gradle
3. Activity lifecycle
4. Intents and screen communication
5. Resources, themes and configuration
6. Runtime permissions
7. Lists and RecyclerView concepts
8. Local data storage
9. REST API and networking
10. Debugging, testing and build variants
11. Practical project and assessment

**Suggested duration:** 2 weeks, 2–3 hours daily.

## Completion target
Build a starter app with two screens, explicit and implicit Intents, a permission request, a sample list, local preference storage and a sample REST API request.

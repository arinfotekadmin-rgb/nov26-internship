# 12. Responsive Layouts and Accessibility

Do not assume every device has the same width, height or orientation. Use flexible modifiers and adaptive layouts. A phone may use one column; a wider tablet may use two.

Test:
- Narrow phones.
- Large phones.
- Tablets and landscape orientation.
- Increased system font size.
- Display cutouts and system bars.

### Accessibility checklist
- Use readable text and sufficient contrast.
- Add descriptions to informative images.
- Give controls clear labels.
- Do not communicate status through colour alone.
- Use comfortable touch target sizes.
- Support system font scaling.
- Test with TalkBack where possible.

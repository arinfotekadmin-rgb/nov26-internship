# 11. Images, Icons and Resources

Use local drawable resources for app-owned images and icons. For remote images, use a suitable image-loading library and handle loading and failure states.

### Image guidelines
- Compress images for their display size.
- Add content descriptions to meaningful images.
- Mark decorative images appropriately.
- Do not stretch the company logo.
- Use assets that you own or are licensed to use.

### Exercise
Add an AR INFOTEK logo, three course illustrations and useful accessibility descriptions. Check the result on different screen densities.

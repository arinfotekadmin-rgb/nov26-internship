# Batch 4: Jetpack Compose UI Development

**Goal:** Build modern Android screens using Kotlin and Jetpack Compose.

Compose is a declarative UI toolkit. You describe the interface for the current state. When observed state changes, Compose updates the relevant UI.

## Chapters
1. Compose mental model and first screen
2. Composable functions and previews
3. Column, Row and Box
4. Modifiers and styling
5. Material 3 and themes
6. State and recomposition
7. State hoisting and UI events
8. Forms and validation
9. LazyColumn and course catalogue
10. Navigation Compose
11. Images, icons and resources
12. Responsive layouts and accessibility
13. ViewModel, UI state and repository
14. Coroutines and Flow
15. Compose testing and debugging
16. AR INFOTEK Learning App project
17. Assessment and study schedule

**Suggested duration:** 3 weeks, 2–3 hours daily.

## Completion target
Build a multi-screen app with a branded home screen, course catalogue, course details, registration form, contact screen, validation, navigation and sample data.
